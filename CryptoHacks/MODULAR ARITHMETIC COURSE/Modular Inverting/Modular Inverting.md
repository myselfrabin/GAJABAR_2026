## RESEARCH ON MODULAR INVERTING: 

- **Modular multiplicative inverse** and Modular Inverting both are same.
### DEFN: 
- A modular multiplicative Inverse of an integer `a` is an integer `x` such that the product `ax` is `congruent to 1` with respect to the modulus m. 
$$a.x \equiv 1 \pmod{m}$$

## SO WHAT'S CONGRUENT: 
- For a given positive integer n, two integers a and b are called congruent modulo n written
$$a \equiv b \pmod{n}$$

	- if a - b is `divisible` by n (or if a and b have the same remainder when divided by n).
